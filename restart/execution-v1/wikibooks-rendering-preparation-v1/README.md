# Offline DOM renderer prototype

This isolated prototype fixes a specific text-rendering defect: `get_text(' ', strip=True)` inserts spaces between adjacent inline nodes that can split a single word. `render_block_text(node)` concatenates inline text literally, folding only ASCII whitespace actually present in normal HTML flow. It preserves nonbreaking spaces and Unicode codepoints; it does not guess missing spaces or normalize words. Explicit `br`, repeated `br`, paragraph and list boundaries remain. `pre` uses original DOM text adjacency and source whitespace, avoiding token-per-line insertion from inline syntax highlighting.

`render_blocks(content)` returns independent highest structural blocks, hashes, combined text, and review holds. Original HTML stays byte-for-byte in `render_html` output and is separately saved for this first-page comparison. Math and tables receive explicit placeholders and whole-page review holds. Superscript/subscript formatting also holds a page because plain text cannot establish that mathematical, chemical or reference meaning survives. This is deliberately conservative preparation, not an admission rule frozen for a source cohort.

The renderer does not compute CSS/layout or implement the complete navigation/removal, metadata, rights, dependency or ancestry policy. Integrators should retain those existing steps and use the renderer only for text construction, adding rather than removing its holds. No existing extractor or result is modified here.

`check_synthetic.py` verifies 30 named cases, including fragmented words, links, punctuation, source spaces, repeated breaks, nested lists/paragraphs, verbatim preformatted source with inline highlighting, Unicode/entities, math/table holds and exact original HTML retention. Run with the existing system `python3` environment containing BeautifulSoup/lxml; no package installation is needed.

`compare_first_page.py` reads exactly the first existing source record and compares both renderers over the same raw-DOM structural blocks. It does not claim full extraction-pipeline equivalence. The retained page is 466758, revision4390816. Eight of24blocks change, including `Onl in e`→`Online` and `in formation`→`information`. This first-page comparison establishes the mechanism only; it is neither a representative quality review nor factual/rights clearance. No data admitted, network used, or model initialized.
