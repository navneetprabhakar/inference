Actual verification requires a separately parent-reviewed terminal binding with externally supplied SHA256, COMPLETE producer receipts, absent source PIDs and exact immutable-in-practice output file stats/hashes. This does not change the six-hour producer budget or grant retry authority.

One read-only frame integrity/FK check; one PK-ordered page/index-subset/group/JSONL-receipt pass; one revision-PK pass. Every selected page ID and ordinal matches the already globally unique index subset. Raw numeric lexemes/UTF8 lines/hash/length/LF and raw index identity transcript are independently reconstructed. Expected semantic titles use the pinned strict XML-once decoder; actual producer title transcripts must match. This independently checks projection and coverage; no source XML is reparsed or page hashes recomputed. Exact first1,600 page rawhash/group-local spans/text bytes/revision IDs and first16 compressed hashes bridge the prior separately verified whole-page algorithm. All page spans remain within decoded groups and nonoverlapping.

A seen bitset tracks each page-local revision occurrence while streaming the revision Btree. Range+no repeated bit+observed total==sum expected proves per-page occurrence bijection without queries per page, global Python sets or SQL grouping/sorting. Original root stays open; no closure/native bytes are invented.

Producer artifact hashes, independent parent binding, FD/path stats before/after SQL and inherited source/index custody must agree.
