Start a conversation:
  curl -s http://127.0.0.1:8765/api/chat \
    -H 'Content-Type: application/json' \
    -d '{"message":"Use the calculator to subtract 19 from 73.","permit_calls":true}'

The response includes session, answer, trace (actual offline tool results),
frames, and failure. Pass the returned session to continue:
  curl -s http://127.0.0.1:8765/api/chat \
    -H 'Content-Type: application/json' \
    -d '{"session":"PASTE_RETURNED_SESSION","message":"What was the result?"}'

Omit session to start fresh. Optional id provides idempotent retries within that
session: reuse the same id/message/permit_calls after an uncertain response.
Changing a request under an existing id returns409. Tools default off per turn;
available tools are calculate and length conversion(m/cm/mm/km), not web or shell.
At most2calls per turn and4per session. Browser has a per-turn tools checkbox.

Runtime: loopback only, one inference at a time, up to16 in-memory sessions,
64turns/session, no silent context trimming. Restart loses sessions. A malformed
model action is shown as a failure; use New chat to reset a blocked conversation.
Browser endpoints /api/session and /api/turn remain available too.
