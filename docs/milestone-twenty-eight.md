# Explicit styles and separate meaning diagnostics

Creator: Navneet Prabhakar

## Delivered

- CLI prompt v3 adds `five-styles-v1`: professional uses precise complete sentences; casual uses relaxed everyday English; terse removes nonessential words; humorous adds light non-factual wordplay; caveman uses intelligible clipped clauses/fragments. Style must affect diction/syntax without changing facts, units, negation, references, corrections, uncertainty, actions or content setting.
- V3 retains the post-tool final-answer contract and canonical schema ordering. The full style guidance is included in the request identity and submitted-prompt hash. The active CLI configuration selects v3; v1/v2 prompt bytes, instructions and cached identities stay unchanged. Earlier real records remain readable through the bridge.
- Meaning diagnostics report structured oracle checks separately from prose observations. Numeric literals outside the oracle and negation markers are review cues only. They do not verify number words, units, negation scope, reference resolution or truth; correct metadata can accompany a wrong reply.
- Style-pair diagnostics compare only the same semantic scenario/context, requested model and prompt version. Case, whitespace and valid integer grouping differences are ignored for a conservative nonseparation cue. Different text is not a style pass. Meaning/style/human approval flags remain false, with no automatic admission or rejection based on these surface cues.
