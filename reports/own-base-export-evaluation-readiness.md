# Own-base export and real inference preparation

The export/loader and development runner are prepared and CPU-tested. No production checkpoint was exported, no candidate was evaluated and no GPU job or activation specification was created.

`own_base_sft_export.py` verifies the completed, protected SFT endpoint separately from its selected optimizer parent: own random-init lineage, exact data/schedule progress, attempted versus committed work, optimizer recipe, parameter inventory/cap and RNG evidence. It writes a new immutable bare-weight export with status `candidate_for_development_not_release`. Root reran eight tiny CPU tests. Independent review found and the implementation fixed a weights hash/load race and acceptance of `maximize=True`; descriptor-bound loading and optimizer mismatch regressions now pass. Parent tensors are released before scanning the SFT endpoint to control peak memory. The CPU wall ceiling is cooperative; MPS RNG bytes are checked against verified-parent layout without restoring them on a GPU.

`own_base_dev_run.py` requires an explicit candidate, runtime/corpus hashes and budgets. It uses the actual own model with greedy decoding, complete Chat history and real broker observations. It reserves worst-case 256-token frame costs before forward execution, records actual observed costs separately, and does not assume that a two-call execution quota prevents further model proposals. Canonical GPU exclusion, inherited STOP paths, process-group resource monitoring and a foreground deadline watchdog protect execution. There is no automatic retry, alternative model or host answer fallback.

The fixed development inventory is 422 primary tool sessions / 583 turns, eight four-call sessions / 24 turns, and 12 public conversation sessions / 25 turns: **442 sessions / 632 turns**. The corrected primary rubric compilation is v4; longer-session rubrics are v2. Incomplete runs cannot produce a complete aggregate score. Manual judgments remain pending; source-answer controls are not model results or release evidence.

Root reran nine runner CPU check groups, including actual tiny argmax parity, pre-forward reservation, interrupted-frame accounting, owned-child watchdog refusal and output exhaustion immediately after real arithmetic execution. A bounded emergency receipt preserves available tool results and dispatch decisions before ordinary abort reporting; reserved space protects worker and parent terminal records. Oversized frames have explicit omission markers. A hard kill cannot recover unflushed RAM and remains explicitly incomplete/unknown.

Remaining integration evidence must come from the actual selected own-base SFT endpoint, its export, real MPS inference and full transcript adjudication. The existing protected delivery gates and current live preview remain unchanged.
