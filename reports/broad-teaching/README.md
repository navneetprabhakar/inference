# Offline fallback conversation curriculum

**127 histories supply 8,200 supervised assistant tokens.** This is a separate, compact supplement to the existing practice sets. It covers extracting source facts, following a correction, narrowing or transforming a previous answer, and responding to an actual second question. A different custodian must check protected-set overlap before training.

| Source | Histories | Composition |
|---|---:|---|
| Dolly | 89 | 25 histories join different original questions on exactly the same source passage. In 48 others, an assistant-authored follow-up revises, extracts, reorders or narrows the original answer. The remaining 16 have a single exchange. |
| OpenAssistant 2 | 38 | Complete two-exchange English paths from distinct original trees. Each follow-up genuinely follows the preceding user and assistant messages. Several follow-ups are acknowledgments. |
| Combined | 127 | 111 have two exchanges. At the project tokenizer/framing version, 107 fit within 256 input tokens, all fit within 378. |

## Sources and selection

- **Dolly.** Developed by Databricks and licensed under CC BY-SA 3.0. Its card also credits Wikipedia editors and contributors for the context passages. The original release exposes its article attribution at the collection level. `selection.json` records the original zero-based line number for every selected question. `broad_teaching.py` verifies the full published raw hash and requires the question/answer pair to appear in an archived training-designated shard. The original question, context and response are preserved after trimming outer whitespace. Joined turns share the identical source passage, which appears only once. Editorial follow-ups and their answers are explicitly identified in the selection. Historical statements and counts should be interpreted in the supplied passage's context. [Pinned source and attribution](https://huggingface.co/datasets/databricks/databricks-dolly-15k/blob/bdd27f4d94b9c1f951818a7da7fd7aeea5dbff1a/README.md)
- **OpenAssistant.** The source card specifies Apache-2.0. The full source and license file hashes are verified locally. Selected trees have official train membership under the pinned archive map, and the final assistant reply is present in a separately archived local training shard. The loader follows the actual parent IDs through the raw tree, enforces alternating speakers, and requires every node to be approved, English, human-authored and retained. Positive privacy, spam, language mismatch, inappropriate, violence, hate or sexual-content flags exclude the example. Selected assistant replies also needed source quality at least 0.5. The selection records only tree/reply IDs, and the loader exports message roles and text. The 12 OASST trees in the previous chat curriculum were excluded. [Pinned source and attribution](https://huggingface.co/datasets/OpenAssistant/oasst2/blob/179dd21fc55192153d94adb0e0ce8f69e222bf75/README.md)
- **Scope of review.** An assistant screened 202 candidate OASST trees meeting initial length, moderation and source-split filters, read the complete shortlisted paths, and selected 38. Exclusions included plausible but inaccurate answers, stale service advice and responses that missed the follow-up. Dolly source selection emphasized answers supported in the passage, useful classificatory or editorial responses, and compact completion lengths. The editor checked the source question, answer and supporting span for grounded examples, and directly authored the marked follow-ups. Generic acknowledgments, clumsy source prose, encyclopedia/trivia bias and sparse naturally occurring rewrites remain limitations. The total target-token count is too small to establish broad instruction following on its own.

## Reproduce

From the workspace, run `.venv/bin/python broad_teaching.py` to verify the local sources, validate every history through the training serializer and regenerate `receipt.json`. Use `broad_teaching.examples(seed)` for a shuffled list of ordinary role/text histories. Different seeds change only their order. Source text stays in the licensed archives. This package contains source references and the new editorial continuations. The preparation accessed training records and source metadata only. It used no network, training process or GPU.
