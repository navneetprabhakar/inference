# Explicit command handling in the assistant preview

The local CPU checkpoint and its learned heads stayed fixed. A preview-only host selector recognizes a full binary calculator command or one conversion with a numeric quantity and explicit units. Polite prefixes and calculator/converter suffixes are accepted. A single reference can resolve to the latest successful host event, including a contradictory fixture result. Unit aliases, compatibility checks, numeric limits, permissions, call IDs, execution, and error/result records use the existing tool interface. The selector contains no arithmetic implementation.

If the learned proposal matches every typed field, it retains its original caller label. Otherwise the validated host proposal is labeled `host/explicit-command-serialization`. Both paths use the actual fixture response. A clear unsupported unit, permission denial, missing prior result or incompatibility returns `host/explicit-command-notice` with no tool event. On an obviously conditional, prohibitive, quoted, or comparison-led utterance, a spurious learned proposal can also be vetoed. Unrecognized conversation remains subject to the existing backend.

The independently authored full-checkpoint CPU screen used 16 commands and nine non-command controls, before and after. Command checks required the specified number of real events and the expected answer or clarification. Five passed before and all 16 passed after. Of the latter, five executed via the agreeing learned head, four used the host proposal, and seven gave a host notice. Three negative controls caused unintended calls before and zero did after. This small, internal screen was used during development. It provides no estimate of performance on unseen conversation. Its controls count tool execution rather than conversation quality.

Reproduce locally using `.venv/bin/python verify_preview_commands.py before` and `.venv/bin/python verify_preview_commands.py after`. The baseline composes the unchanged reference/readback product without the new host selector. The resulting JSON files include actual origins and broker traces. No live server reload was performed for these measurements.
