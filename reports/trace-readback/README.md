# Optional latest-call readback

Use `trace_readback_chat.Chat(model, tok, guard)` to opt in. Existing entry points keep their prior behavior. The learned component uses CPU inverse-document-frequency weighting and nearest labeled exemplars to select the question intent. Runtime scope checks reject compound, out-of-vocabulary and ambiguous numeric questions. A deterministic renderer reads the last host event, checks that the requested argument exists, and returns the actual argument, tool name, observed error, recorded result, or comparison verdict. It never recomputes the tool's answer. The selected path is `learned-readback/host-trace-render`. Abstentions continue through the v2 product, which has its own recall and tool behavior.
