# Grounded curriculum packing

Use `pack_grounded_sft.py` only after complete matching independent candidate verification and both historical/private and public-development custody receipts exist. Each receipt must bind the same candidate database and manifest; the public receipt also binds the independent verification receipt. Historical chat custody binds it as well. Historical tool custody predates that field, so the packer separately requires the matching independent candidate proof.

The packer freezes all six candidate/proof artifacts, runtime code and tokenizer assets before writing any streams. It rejects missing/stale/partial proofs and excludes the union of both custody lists. All retained original histories are reserialized through the unchanged own-base host framing. Counts must exactly match independently verified candidate counts; an unexpected mismatch or fit failure aborts the output. No selection refill, data repetition, truncation or input repair occurs. The whole original candidate inventory and every exclusion ID must be accounted for.

Outputs are new direct children of data/, never overwritten. Training and development receive separate uint16 input/label streams and row indexes, with current-turn target masks and complete histories. Validation is consistently named exposed-development in new outputs. Caps remain chat540k/60k, primary270k/30k and four-call90k/10k targets. After custody exclusions these are ceilings, not quotas to refill. Runtime limits are30minutes,1GiBRSS,1GiBoutput and20GiBfree disk with root/source/destination STOP checks.

A preparation receipt is not admission. Independent packed-stream verification must prove every retained row agrees with the reviewed candidate, the union exclusions, exact tokens/masks/offsets, whole-history inventory, train/development family separation and final counts. Four-call qualification must additionally bind observed2+2+0histories to retained final-turn rows. New diagnostic admission wrappers, resource allocation and hardware preflight follow those checks. Original datasets, receipts, source runtimes and failed model evidence remain unchanged.

Synthetic proof-boundary regressions cover exclusion union, missing public proof, changed database, stale/incomplete/duplicate custody lists, builder-selfcheck rejection and uint16 mask/position encoding. They do not establish candidate quality or replace independent stream verification.
