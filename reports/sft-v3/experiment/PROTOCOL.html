Two-arm local repair experiment

Two independent 2M-input-slot continuations from the frozen 100M + 5M SFT LR 3e-5 checkpoint. Fresh AdamW optimizer per arm; identical frozen data order. 256MiB cache ceiling, sequential execution, existing resource guards, continue on battery. Startup validation tokens count inside the first arm budget.

Source weights multiply only supervised labels. Fractional target mass is preserved and used to normalize accumulated gradients. The desired 50/25/10/15 source share is aggregate weighted target mass, not a claim that gradients or learning gains follow that proportion.

Four development evaluations at 1M/2M snapshots plus both existing references precede selection. One fresh-test release scores the selected candidate and both frozen references. There is no automatic checkpoint promotion, test-driven reselection or extension; stop for review. Chat quality remains pending blind review.
