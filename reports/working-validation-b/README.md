# Independent validation B

This set is separate from primary development selection and from the sealed 100-conversation confirmation run. Reserve it for one follow-on candidate selected before opening B. The set contains 20 sequential sessions with two user turns each: ten prose, six tool and four no-call. It has 19 scenario families, including a paired recorded-fixture family whose two sessions differ only in the observed tool value.

The freeze binds the cases, strict scorer, curriculum pool identities and pre-use custody audit. The full supplemental pool passed the primary-development and sealed-confirmation screens. An initial B draft matched call signatures in 13 existing tool histories. Two scenarios received different numeric fixtures before any model was run. The final B screen found zero matches across all four named teaching pools. The custodian retained the draft privately. The lexical and signature screen cannot prove semantic independence across every upstream data source.

Every scripted CPU control used the actual chat protocol and offline broker. These controls verify interfaces and scoring only. B remained unused for student model selection at freeze time.

For a preselected model already holding the device guard, use `evaluate_validation_b.evaluate_b(model, tokenizer, guard, fresh_output_dir, identity)` with a pinned checkpoint SHA in the identity. Reports include all raw frames, traces and reasons, with separate whole-session, first-call and actual-result grounding counts. A baseline or challenger tested on B makes it exposed development data for future iterations.
