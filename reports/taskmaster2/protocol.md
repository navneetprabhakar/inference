## Admission protocol

Admission uses the first natural source request followed by one or more real, consecutive assistant clarifying questions. Minor disfluencies and stylistic roughness pass. A question that requests information already supplied, assumes a new ungrounded option, claims an external result, seeks an identifier, or materially ignores a clear request fails. For each use and domain inspect six frozen-candidate train conversations using the public salt tm2-quality-v2. Include only domains with at least five of six usable, no sensitive examples, and hold individual failures. If there are fewer than six rows, review all rows. A materially revised filter may be assessed using a new salt; published failures must remain explicit.

Pretraining-only admission requires an understandable human preference. It can include the preceding clarifying question. It must be kept out of assistant-supervised training. Publisher-internal scenario roleplay limits how much weight the corpus deserves. Newly isolated instruction goals belong to an internal-development split and require separate evaluation before they can serve as any measure of transfer. No sealed cases are used to tune filters.
