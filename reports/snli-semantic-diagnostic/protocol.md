# CPU diagnostic fixed design

Fit a regularized three-class linear classifier on the published source-only NLI training histories after enforcing the pinned independent custody denylist. Primary experiment trains/evaluates only the unanimous tier. A separately reported sensitivity run includes the eligible single-judgment tier with balanced weight per tier/label, while leaving the primary validation population fixed. Use identical token normalization, hashed lexical features, objective and optimization for each model. Compare hypothesis alone, unaligned premise+hypothesis bags, and lexical pair matching based on shared, missing and added words and phrases. Fit with no development tuning. The accuracy result concerns held-family SNLI pairs and none of the project cases.

Report original predictions on the whole internal validation split, unanimous rows alone, and slices excluding explicit negation in the hypothesis or in either sentence. Macro recall is the class-balanced score. Report all three denominators, confusion matrices, gains/losses relative to the hypothesis-only model and matched source-family bootstrap intervals on the primary consensus comparison. As a dependence check evaluate the already fitted pair model with premises deterministically reassigned within validation tier and nearby sentence-length bins, keeping original gold labels only as a sensitivity control. Separately count identical validation hypotheses whose actual premises produce different human relation labels. Preserve source-family disjointness and never use these controls to choose a model or alter the student.

After the primary and sensitivity comparisons were read, add one explicitly exploratory ablation with the identical train/optimizer/validation procedure. Keep hypothesis features and use only generic overlap bins, length/negation and count features from the premise. Omit premise-word identities and the identities of shared or novel words. This measures whether simple admission-correlated overlap cues can account for most of the observed improvement.
